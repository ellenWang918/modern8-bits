# Button

Buttons trigger an action or move someone to the next step. Use a short, clear label that describes what will happen.

## Overview

The Button component has contained, outline, ghost, and pixel treatments, plus a disabled state and three sizes. It uses semantic theme tokens, so its colors adapt when you switch the Storybook appearance between light and dark.

## Variants

Use contained for the main action, outline or ghost for lower emphasis, and pixel for a selective stepped accent.

### Sizes

Small, medium, and large use the authored 32/40/48px visible heights. Use large controls for touch-heavy layouts. Allow adequate spacing around compact controls; visible height alone does not establish touch-target suitability. Ordinary labels use IBM Plex Sans; pixel labels use IBM Plex Mono.

### Icon only

Icon-only buttons use the same four treatments across small, medium, and large sizes. Each button has an accessible label for assistive technology.
