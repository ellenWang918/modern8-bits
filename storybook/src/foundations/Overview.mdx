# Modern8-bits Design System

A design system for building clear, contemporary web products with a touch of 8-bit nostalgia. Shared foundations make everyday design decisions easier; optional pixel details add character.

## Who it is for

Modern8-bits supports designers, developers, and people building with coding agents who have little or no design experience. Its neutral visual language can support different industries, while content and imagery give each product its own identity.

## Design principles

- **Clarity first.** Use readable typography, clear hierarchy, and predictable interactions.
- **A coherent foundation.** Shared colour, typography, spacing, and geometry rules keep components consistent.
- **Character with restraint.** Keep everyday interfaces neutral; use pixel accents deliberately.
- **Meaning survives presentation.** Preserve labels, focus, feedback, and behaviour in both finished and low-fidelity views.

## Current scope

The current release focuses on mobile-first, responsive web interfaces:

- Colour, typography, spacing, layout, geometry, and motion foundations.
- Five React components: Button, Input, Checkbox, Badge, and Card.
- Default and low-fidelity presentations, each with independent light and dark appearances.

Product patterns, native components, industry presets, and product-level theme customization are outside the current release.

Figma authors the design decisions; code is synchronized manually. Supported mappings and differences between Figma and code are documented in Design Token.
