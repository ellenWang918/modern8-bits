# Modern8-bits Storybook

This folder contains the React + TypeScript + Vite component library and Storybook app. Initial components are `Button`, `Input`, `Checkbox`, `Badge`, and `Card`, each with variant and state stories. Shared CSS tokens are in `src/styles/tokens.css` and use the `--m8-` prefix. Import components and their TypeScript types from `src/components`.

Storybook Docs is enabled with autogenerated component documentation, including Controls, prop tables, and story examples.

## Run locally

From this folder:

```sh
npm ci
npm run dev
```

## Open Storybook

```sh
npm run storybook
```

Use Storybook to review component variants in isolation. The Figma file is embedded in the Storybook Design panel as a shared file-level reference. The current Figma file contains a `READ_ME` overview page but no component frames, so it is not a one-to-one visual match. When component frames are added, set story-level `parameters.design.url` values to their Figma links.

## Deploy on Vercel

`vercel.json` builds Storybook and publishes the `storybook-static` output. When importing the GitHub repository, set Vercel's Root Directory to `storybook`.
