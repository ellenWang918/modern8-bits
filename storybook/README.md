# Modern8-bits Storybook

This folder contains the React + TypeScript + Vite component library and Storybook app. Initial components are `Button`, `Input`, `Checkbox`, `Badge`, and `Card`, each with variant and state stories. Shared CSS tokens are in `src/styles/tokens.css` and use the `--m8-` prefix. Import components and their TypeScript types from `src/components`.

Storybook Docs is enabled with autogenerated component documentation, including Controls, prop tables, and story examples.

Start with **Foundation / Getting Started**, immediately after Overview. Its local controls demonstrate default and low-fidelity presentation independently of light/dark appearance. The same five-component example preserves form values, selection and results when switching. Component stories also have a Presentation toolbar. Read [USAGE.md](../USAGE.md) for setup and guidance for people building with coding agents.

The Design Token reference includes the 13 Presentation variables added in Figma, bringing the inventory to 119. See [presentation verification](../.scratch/foundations-first-release/presentation-result.md) for the Figma comparison and recorded checks. These changes are local until deployed.

## Run locally

From this folder:

```sh
npm ci
npm run dev
```

## Open Storybook

```sh
npm run storybook
```

Use Storybook to review component variants in isolation. The Figma file is embedded in the Design panel as a shared reference. Gap 7 aligns 106 variables and 16 text styles, including typography, geometry, layout, and motion. The Design Token page documents current mappings and supported subsets; additional Figma sizes/states and code pixel treatments do not imply identical component APIs. See the [gap 7 results](../.scratch/foundations-first-release/gap-7-result.md). Set story-level design links only after checking the corresponding mapping.

## Deploy on Vercel

`vercel.json` builds Storybook and publishes the `storybook-static` output. When importing the GitHub repository, set Vercel's Root Directory to `storybook`.
