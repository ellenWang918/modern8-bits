# Modern8-bits Handover

## Goal

Build a design system called **modern8-bits**: clean, contemporary, and flexible, with subtle 8-bit warmth. Its personality is captured by **“Quiet UI. Loud pixels.”** Pixel details should act as accents, not turn the interface into a retro game UI.

## Current direction

- Start with black, white, and neutral grays. Let users introduce their own primary colour through semantic theme roles.
- Typography: **Space Grotesk** for display, **IBM Plex Sans** for interface and body text, and **IBM Plex Mono** for utility labels and pixel-inspired details.
- Support responsive experiences across web and mobile, and adapt to fashion, sport, learning, and technology.
- Use Carbon’s **“All about Carbon”** as a reference for explaining the system, not as a visual or copy template.
