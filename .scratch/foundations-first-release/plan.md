# One-week plan

Prepared: 2026-10-04. Day numbers are work sessions rather than a promise of automatic scheduled work.
Target: an honest, coherent foundations demonstration within one week.

| Day | Focus | Concrete output | Ticket |
| --- | --- | --- | --- |
| 1 | Verify Figma and settle the foundation inventory | Current-state inventory, intended variables/styles and CSS mapping, corrected scope claims | 01 |
| 2 | Colour and token architecture | Figma colour variables/modes, matching CSS, status and focus roles, reference checks | 02 |
| 3 | Typography and responsive structure | Figma text styles/scales, matching CSS roles, spacing/layout/geometry documentation | 03 |
| 4 | Apply the foundations | Five existing components aligned; foundation pages show real definitions | 04 |
| 5 | Low-fidelity presentation and agent use | Mode control and examples; concise usage guide with the initial question | 05 |
| 6 | Governance and verification | Worked change, change log, sync checklist, recorded build and usability checks | 06 |
| 7 | Interview preparation and final repairs | Short walkthrough, traceable examples, remaining limitations, final readiness review | 07 |

## Work order

Execute tickets in number order. Dependencies are explicit in each ticket. A ready-for-agent status means the ticket is specified; it does not mean dependencies are already completed.

Figma decisions precede corresponding code updates. Reuse existing assets and components. Inspect before editing; do not replace existing Figma material blindly.

## If time becomes tight

Reduce the number of decorative examples and polish passes before reducing core coverage. Keep token/type clarity, Figma/code mapping, the two presentation paths, essential checks, and honest governance evidence. Do not compensate by adding product screens or claiming unverified parity.

## Review evidence

Keep check results and limitations with the relevant issue. A configured tool or written guideline is not a successful validation result. Finish by documenting exactly what can be demonstrated.
